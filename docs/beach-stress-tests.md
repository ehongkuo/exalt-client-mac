# Version 7: one beach run

Launch the game through the rebuilt **Exalt Client Mac** app with a disposable character.
Enable **Armed** and **Nexus on death**, Apply, and wait for **Nexus on death ready** in Nexus.
Turn auto-potions off; natural regeneration can stay on.

1. Enter the Realm and let weak beach enemies steadily chip away at your HP until automatic
   Nexus or an unexpected death.
2. Wait five seconds afterward with the app/game open, then report **done**.

No separate sessions, manual labels, recording or uploads are needed. The recorder saves recent
history automatically on a successful escape request or observed death. We locate the latest
session and inspect incoming HP updates, local damage, retained damage, the escape reason,
suppressed reports, and resulting map/HP. A successful request alone does not establish survival;
we also check for arrival alive in Nexus.

If you want to stop before an automatic escape, manually Nexus; that also saves recent history.
Stop after any death, stuck escape or apparent full-health false escape, and report what you saw.

Healing, delayed and unchanged HP updates, network stalls, ledger exhaustion and injected timing
variations already have offline regression coverage. This single live run checks integration with
ordinary game traffic; it does not independently validate every damage source or timing condition.
The experimental guard can still fail or escape early.
