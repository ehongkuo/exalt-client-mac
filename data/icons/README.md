# Game icons

Realm of the Mad God art, © DECA Games, used to show items the way the game does:

- `Enchants-Uncommon.png`, `Enchants-Rare.png`, `Enchants-Legendary.png`, `Enchants-Divine.png`: the rarity marks
  (one gem per enchantment slot), 16×16.
- `Shiny.png`: the shiny mark, 50×50.

Copied from [RealmHound](https://github.com/pillarzz/RealmHound) (`crates/realmhound/assets/`), which took them from the
game's interface textures. RealmHound's MIT license covers its code, not this art. The app draws its own gems when these
files are missing.
